CrossPoint Uploader

Subida binaria directa por WebSocket, sin servidor propio.

WebSocket binary upload

Esta app abre una conexión a ws://crosspoint.local:81/, envía el mensaje START:<filename>:<size>:<path>, espera READY y después transmite el archivo en bloques binarios. Está pensada para correr solo en el navegador, usando HTML + CSS + JavaScript.
